# FinanceHub – Corporate Finance & Audit Intelligence Platform

## Overview

FinanceHub is a web-based Corporate Finance & Audit Intelligence Platform developed by **Sugadev V** as an MBA Finance portfolio project. The platform combines financial analytics, budgeting, audit monitoring, valuation, and executive reporting into a single interactive dashboard.

## Features

### 📊 Dashboard

* Revenue Forecasting
* EBITDA Analysis
* Cash Flow Monitoring
* Interactive KPI Cards
* Revenue Trend Visualization

### 💰 Budget vs Actual Analysis

* 12-Month Budget Planning
* Actual Performance Tracking
* Variance Analysis
* Variance Percentage Calculation

### 🏦 Concurrent Audit Tracker

* Audit Observation Register
* Risk Classification (High, Medium, Low)
* Status Tracking
* Audit Summary Dashboard

### 📈 DCF Valuation

* Revenue Growth Assumptions
* EBITDA Margin Analysis
* Tax Rate Inputs
* WACC Inputs
* Terminal Growth Calculation
* Enterprise Value Estimation

### 📑 Executive Reports

* Financial Performance Summary
* Audit Observation Summary
* Enterprise Value Reporting
* Excel Export Functionality
* Printable Management Reports

## Technologies Used

* HTML5

* JavaScript
* Chart.js
* Local Storage API
